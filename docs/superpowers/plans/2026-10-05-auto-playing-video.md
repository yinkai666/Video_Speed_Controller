# 自动跟随播放视频实现计划

**目标：** 多视频页面无需点击选择按钮，快捷键自动控制最近开始播放的视频。

**行为约定：** 首次扫描优先选择正在播放的视频；多个视频同时播放且没有播放历史时，使用已有站点主播放器规则，再按 DOM 顺序选择。监听后最近开始播放的视频优先。当前视频暂停或结束时切换到其他正在播放的视频；全部暂停时保留当前目标。手动按钮临时选择目标，下一次视频开始播放时恢复自动跟随。切换目标先结束旧视频上的长按，松键不能误快进新目标。

**实现：** 在现有 VideoController 中登记每个视频的媒体监听、播放顺序和默认倍速应用状态。扫描和媒体事件共用目标选择及按钮高亮逻辑；重复扫描保持幂等，移除和清理时解绑监听。使用媒体事件，不增加轮询。

新发现的一批已播放视频优先于之前登记的视频，同批视频用站点规则兜底。发现的视频位于开放 ShadowRoot 或同源 iframe 时，观察对应根节点的变动。清理取消防抖扫描，异步初始化不覆盖期间收到的播放选择。

**范围：** 修改 video-speed-controller.js、多视频使用说明，新增 Node 内置测试；保留单文件油猴发布形式，不引入依赖。
